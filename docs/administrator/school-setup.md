# School setup and academic years

## The setup checklist

While a school is being set up, the **Overview** page shows a setup checklist with eight steps in order. Each step links to the page where you complete it:

1. **School profile** — add the school's name and details.
2. **Academic year** — create the first academic year.
3. **Classes and sections** — add at least one Class/Grade and Section.
4. **Subjects offered** — add at least one Subject.
5. **Teacher accounts** — create at least one teacher account.
6. **A class teacher for every section**.
7. **A subject teacher for every subject**.
8. **Every student placed in a section**.

## Enter school details

The school details are the identity used on documents and in guardian messages.

1. Go to *School setup > School*.
2. If no details exist yet, complete **Create school configuration**. Otherwise select **Edit**.
3. Enter the school name, address, affiliation number and principal name.
4. Choose how guardian messages are handled:
    - **Portal only** — guardians see messages after signing in to the Guardian Portal.
    - **Prepare WhatsApp messages for office staff to send** — School ERP prepares the message text; office staff send each message themselves and record whether it was sent or skipped. School ERP never sends WhatsApp messages automatically.
5. Select **Save school details**.

!!! note
    PDF letterheads use the school's text details. The uploaded logo is shown in the signed-in interface; it is not printed on PDF letterheads.

### Upload or remove the school logo

1. On *School setup > School*, select **Upload logo** (or **Replace logo** if one exists).
2. Choose the image file. Select **Cancel selection** if you chose the wrong file.
3. To remove the logo, select **Remove logo** and confirm.

## Create an Academic Year

An Academic Year holds its calendar, terms, subjects and teacher assignments. Its dates are used for enrollment, attendance, assessments and reporting.

1. Go to *School setup > Academic Years*.
2. Select **Create Academic Year**.
3. Enter the name (for example *2026–27*), the start date and the end date.
4. Choose whether Saturdays are instructional.
5. Select **Create academic year**.

Each Academic Year appears as a card with links to its **Calendar**, **Teaching** and **Assessment** pages.

## Set the school calendar and holidays

The calendar decides which days are school days. Attendance is expected only on instructional days, and attendance percentages ignore non-school days.

1. On the Academic Year card, open **Calendar**. The page is titled **School calendar**.
2. To change the weekly pattern, select **Make Saturdays instructional** or **Make Saturdays off**.
3. To add a single-day exception, select **Add exception** and choose the **Type**:
    - **Holiday / closure (no attendance expected)**, or
    - **Extra instructional day (e.g. working Saturday)**.
4. Enter the date and an optional label (for example *Sankranti*), then select **Save calendar exception**.
5. Use **Check** to see how any date is treated, **Edit label** to rename an exception, or **Remove** to delete it.

!!! warning "Calendar safeguards"
    School ERP protects dates that already have attendance. You cannot turn a date into a holiday, or remove an exception, while an attendance register exists for that date; the change is refused with an explanation. Plan holidays before the term starts where possible.
