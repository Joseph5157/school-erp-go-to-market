# School documents

<p class="erp-draft" data-search-exclude><strong>Draft.</strong> Verify against the deployed build before sharing.</p>

School ERP issues three types of PDF from *Daily > Documents*. Issued documents receive a serial number by document type and Academic Year, and are kept as a permanent record.

| Document | Use |
|---|---|
| **Bonafide certificate** | Confirms that a student is currently enrolled. |
| **Report card PDFs** | A student's current published Term report card. |
| **Attendance summary** | Submitted attendance for one Section over a date range. |

## Issue a bonafide certificate

1. Go to *Daily > Documents* and choose **Bonafide certificate**.
2. Choose the student and the purpose: **Opening a bank account**, **Passport application**, **Scholarship application** or **Other**. For Other, enter the purpose in **Purpose (if Other)**.
3. Select **Issue certificate**.

The next serial number is assigned and the PDF opens. The student must have a current enrollment.

## Download a report card PDF

1. Go to *Daily > Documents* and choose **Report card PDFs**.
2. Choose the student and select **Show report cards**.
3. Select the PDF for the Term.

Only the current published version of each report card is listed. Corrected, replaced or withdrawn versions are never listed.

## Issue an attendance summary

1. Go to *Daily > Documents* and choose **Attendance summary**.
2. Choose the Section and a date range inside one Academic Year, then select **Show summary**.
3. Check the table of days present, absent, counted and percentage for each student.
4. Select **Issue PDF with serial number**.

Only submitted attendance is counted.

## Recently issued documents

The **Recently issued** list on *Daily > Documents* shows the latest 50 documents with serial number, type, student and issue time. Opening a PDF again reprints the stored copy; it does not issue a new serial number.

!!! note "What documents contain"
    PDFs use the school's text details as a letterhead; the school logo is not printed. The PDF engine includes Latin and Telugu fonts, but this does not mean the interface or student names support Telugu. Transfer Certificates are not available until a school's required format is agreed.
