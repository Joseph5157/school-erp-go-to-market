# Announcements and messages

<p class="erp-draft" data-search-exclude><strong>Draft.</strong> Verify against the deployed build before sharing.</p>

School notices appear in the Guardian Portal as soon as they are published. Sending them on WhatsApp is an optional, separate step carried out by office staff.

!!! info "Everclass ERP never sends messages itself"
    There is no automatic SMS, email or WhatsApp delivery. With **WhatsApp Assist**, Everclass ERP prepares the message text and a WhatsApp link; a staff member opens it on their own phone, sends it, and records the result.

## Publish a notice

1. Go to *Daily > Announcements* and select **New notice**.
2. Enter a title and the message. The message is plain text and keeps line breaks.
3. Choose the audience: **Whole school**, **One class** or **One section**, and select the class or section if needed.
4. Select **Preview notice**.
5. Check the preview, then select **Publish notice**. Select **Back to edit** to make changes first.

Published notices cannot be edited. To correct one, withdraw it and publish a new notice. **Use as new notice** on an existing notice copies its content into a new draft.

## Withdraw a notice

1. Open the notice from *Daily > Announcements*.
2. Select **Withdraw this notice…**.
3. Enter the reason and select **Confirm withdrawal**.

Guardians can no longer see a withdrawn notice. The reason is recorded.

## Who can see a notice

The notice page shows **Who can see it**: the number of guardians with portal access and the number opted in to WhatsApp for that audience **now**. These are eligibility counts, not view or delivery counts.

## WhatsApp Assist

WhatsApp Assist is available when the school setting is **Prepare WhatsApp messages for office staff to send** (see [School setup](school-setup.md#enter-school-details)).

### Record a guardian's WhatsApp consent

Messages are prepared only for guardians who have opted in. Record each decision on the Guardian page with **Record consent decision**. Consent records are kept as history and are never overwritten.

### Prepare messages for a notice

1. Open a published notice and select **Prepare WhatsApp messages…**.
2. Everclass ERP shows how many opted-in guardians will get a message.
3. Select **Prepare messages**.

Nothing is sent from here. Messages are queued for staff. Guardians without consent are skipped and counted.

Everclass ERP also prepares **same-day absence messages** when attendance is submitted and **report card notices** when report cards are published, for eligible guardians.

### Send from the Message queue

1. Go to *Daily > Message queue*.
2. For each message under **Waiting to send**, select **Send on WhatsApp**. WhatsApp opens in a new tab with the message filled in.
3. Send it from your phone, then return and select **Mark as sent**.
4. If you will not send a message, enter the **Reason for not sending** and select **Dismiss**. Dismissing does not send anything.

Before display and before you mark a message sent, Everclass ERP rechecks the guardian's portal access and consent. If a phone number is missing or not usable, the message says so and the guardian's details need updating.

**Sent today** lists messages marked sent today and who marked them.
