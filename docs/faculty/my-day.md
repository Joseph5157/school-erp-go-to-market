# My day

<p class="erp-draft" data-search-exclude><strong>Draft.</strong> Verify against the deployed build before sharing.</p>

**My day** is the first page you see after signing in. It shows what you need to do today.

## What is on the page

### School day or not

The top of the page shows whether today is a **School day** or **Not a school day**, according to the school calendar.

### Today overview — attendance

If you are a class teacher today, each of your Sections shows its attendance status:

| Status | Meaning | Button |
|---|---|---|
| **Not taken** | No register has been started today. | **Take attendance** |
| **Draft — not yet submitted** | A register has been started but is not official yet. | **Continue** |
| **Submitted** | Today's attendance is official. | **View** |

If you are not a class teacher today, the page says *You are not a class teacher today.*

See [Recording and submitting attendance](attendance.md).

### Today's timetable

Your periods for today, with the Subject and Section, taken from the school timetable. If nothing is scheduled, the page says *No periods scheduled for you today.* The timetable appears only on school days.

### Teaching assignments

- **Class teacher** — the Section(s) you are class teacher of.
- **Subjects I teach** — each Subject and Section you are assigned to.

### Term remarks

For each Term and Section where you are class teacher, the page shows how many remarks are written, for example *12 of 30 written*. Select the row to open the remarks page. See [Class-teacher term remarks](term-remarks.md).

## Tips

- Check **My day** each morning: it is the quickest way to see whether attendance is still to be taken.
- If a Section you teach is missing, your assignment may not have started yet. Ask the school office.
