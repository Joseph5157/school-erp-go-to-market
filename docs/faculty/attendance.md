# Recording and submitting attendance

<p class="erp-draft" data-search-exclude><strong>Draft.</strong> Verify against the deployed build before sharing.</p>

Class teachers take attendance for their Section on the current school day.

## Before you start

- You must be the Section's **class teacher** today.
- Today must be a **school day** in the school calendar. On other days the page shows **Not a school day**.
- You can take attendance only for **today**. For earlier dates, ask the school office.

## Take attendance

1. On **My day**, find your Section and select **Take attendance**.
2. If the register has not been started, select **Start today's register**.
3. The roster lists every student placed in the Section today. For each student, choose **Present** or **Absent**.
4. For an absent student you can add an **absence note**, for example *Informed by parent — fever*.
5. To mark everyone you have not answered as present, select **Mark unanswered as present**. Check the list afterwards.

Use the filters **All**, **Unmarked**, **Present** and **Absent** above the roster to check your work. The counter shows how many students are present, absent and unmarked.

### Your changes are saved as you go

Each row saves itself as a draft and shows **✓ Saved**. If a save fails, select **Retry**. You can also select **Save draft** at any time and come back later from **My day** with **Continue**.

!!! info "Unmarked is not absent"
    A student you have not marked stays **unmarked**. School ERP never treats an unmarked student as absent.

## Submit attendance

1. When every student is marked, select **Save and submit**. Submitting requires Present or Absent for every student.
2. On **Submit attendance?**, check the totals for Present, Absent, absence notes and the total.
3. Read the consequences: the register becomes official, and absence messages may be prepared for office staff to send to guardians.
4. Select **Confirm and submit attendance**.

If you need to change something, select **Back to register**. Your marks are kept as a draft, so going back loses nothing.

## After submitting

- **My day** shows the Section as **Submitted**. Select **View** to see the register.
- A submitted register is **read only** for teachers. If a mark is wrong, ask the school office: an administrator can make a correction with a reason, and the original is kept. See [Permissions and corrections](permissions-and-corrections.md).

## Attendance history

    School ERP has an attendance history page for teachers, but **My day** deliberately does not link to it. How teachers are expected to open it has not been decided yet. This section will be updated once it is confirmed.

The history page shows each Section's attendance for the dates you were its class teacher, with expected, submitted and missing registers, and each student's present and absent counts. Use **‹ Previous** and **Next ›** to move between periods, and **‹ All my Sections** to return to the list of Sections.
